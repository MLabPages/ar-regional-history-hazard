# AR地域理解・歴史・防災統合プラットフォーム MVPプロトタイプ

スマートフォンのカメラ映像に「過去の古写真」「地域の変遷」「防災・ハザードリスク」を一つのAR空間として重ね合わせて表示する統合型WebARプロトタイプです。

## 1. アプリの主要機能

1. **① 歴史・観光レイヤー (History)**
   - 現在地周辺の歴史スポットをARピンとして浮遊表示
   - モーダルから「古写真と現実の景観を比較」を選択すると、ARカメラ画面上で古写真の透過率スライダー（0%〜100%）を使ったリアルタイム重ね合わせ比較が可能

2. **② 地域理解・まち歩きレイヤー (Community)**
   - かつての街道跡（旧京街道）、産業遺構、旧駅跡など「土地の記憶」を可視化

3. **③ 防災・ハザードレイヤー (Disaster)**
   - 国土交通省・国土地理院の公式ハザードタイルを重ねて表示（地点別の深さは公式凡例で確認）
   - 避難所データは公式確認前のため、具体的な施設・方角・距離の誘導を停止

4. **位置・方角シミュレーター (室内・PC検証用)**
   - 実地フィールドワークだけでなく、PCブラウザや室内でも位置プリセットや方位角度（0〜360°）を模擬コントロール可能

5. **AR表示の遠近感・視野外ガイド**
   - 端末のピクセル密度（devicePixelRatio）に合わせてキャンバスを高解像度化し、ピンの文字がぼやけないようにしています
   - ARピンは距離に応じて大きさ・高さ・透過度が変わり、近いスポットほど大きく手前に表示されます
   - 視野（FOV 65°）の外にあるスポットは消さず、画面左右の端に「←/→ スポット名・距離」の方向キューとして表示します
   - スポット名・時代ラベルは文字数ではなく実測幅で省略するため、長い名称でもカードから溢れません

6. **3つの「見る」機能（スポット詳細から起動）**
   - **古写真を重ねて比較**: NDLの絵図・名所絵をカメラ映像に重ね、透過・拡大・角度を調整
   - **年代別の航空写真で見る**: 国土地理院の位置合わせ済み空中写真を1928年頃〜現在で切替表示
   - **3Dで周辺の位置関係を見る**: 実測座標にもとづく立体模式図（建物形状の復元ではありません）

## 2. 開発・検証の起動手順

本アプリは単体Webアプリ（HTML5/JS）として構築されています。
ローカルのWebサーバー（例: Python http.server や Node.js npx serve / Live Server 等）で起動してブラウザからアクセスしてください。

```bash
# Pythonの場合
python -m http.server 8080

# または Node.js の場合
npx serve .
```

ブラウザで `http://localhost:8080` または `http://<PCのIP>:8080` (モバイル実機の場合) にアクセスします。
※ スマートフォン実機でカメラや位置情報センサーを使用する場合は、HTTPS接続（または ngrok / Cloudflare Tunnel 等）を推奨します。

## 4. 資料の正確性・出典管理

年代別航空写真は、国土地理院の公式タイル一覧で確認した定義だけを使用します。

* 1928年頃、1936〜1942年頃、1945〜1950年頃、1961〜1969年頃、1974〜1978年頃、現代最新写真
* タイルが取得できない地域・ズームでは「データがありません」と表示し、別年代や現代地図へ黙って切り替えません
* 大阪向けの明治・江戸・平安の位置精度付きXYZタイルは未収録です

江戸期資料はXYZタイルではなく、NDLの資料ページとIIIFマニフェストを持つ歴史資料として扱います。現在の確認済み候補は「浪花名所図会 八けん屋着船之図」「浪花名所図会 道とんぼりの図」「大坂大繪圖」の3点です。名所絵・絵図は測量図ではないため、概略位置の参考資料として表示します。

大坂の陣に関する3スポット（三光神社・安居神社・一心寺）は、各寺社および大阪市の公式ページで確認した記述だけを掲載しています。ただし「真田の抜け穴」「真田丸の位置」「真田幸村の戦死地点」はいずれも**伝承**であり、史実として確定した遺構・地点ではありません。この3件は `partially_verified` として扱い、`verificationNote` に伝承である旨を明記しています。座標は公式サイト記載の住所からの概略位置（`approximate`）です。

### 画像の利用条件（2026-07-25 確認）

**国立国会図書館デジタルコレクション**

使用している6点はいずれも「インターネット公開（保護期間満了）」の資料です。著作権保護期間が満了しているため、複製・送信などの利用に**手続きは不要で、商用利用も可能**です。ただしNDLは出典表示を求めているため、本アプリでは重ね合わせ画面に機関名・資料名・年代・ライセンス・資料ページへのリンクを**常時表示**し、閉じられないUIとして実装しています。

- 参照: [NDL 複製物の利用について](https://www.ndl.go.jp/jp/use/reproduction/index.html)
- IIIFマニフェストと画像URLは全点HTTP検証済み（200応答を確認）

**国土地理院タイル**

地理院タイルは出典の明示により**申請不要で利用可能**です（商用含む）。航空写真オーバーレイには常に「国土地理院」の出典を表示しています。

- 参照: [国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)

### 重ね合わせの限界について

資料は現実の風景と**ぴったりは重なりません**。これを隠さず、資料種別ごとに理由を明示しています。

| 資料種別 | 表示している注釈 |
|---|---|
| 名所絵・錦絵 | 絵師が構図を整えた作品で測量図ではなく、建物の位置・大きさ・角度は現実と一致しない |
| 江戸期の絵図 | 現代の測量図と作図方法が異なり、方角や縮尺が場所ごとにずれる |
| 航空写真 | 位置合わせ済みだが真上からの撮影で、地上から見た景色とは見え方が異なる |
| 3Dビュー | 建物形状は再現せず、実測座標にもとづく位置関係の模式図。史実の復元ではない |

開発用プレースホルダー画像（無関係なストック写真）は全て削除しました。史料として誤解される画像は表示しません。

NDLの個別IIIF画像リソースIDはHTTP検証が完了するまで本番画面に埋め込みません。資料ページとマニフェストへのリンクを表示し、画像検証済みの資料だけを古写真比較に使用します。

土砂災害（急傾斜地の崩壊）は、公式オープンデータ一覧で確認した大阪府コード27、ズーム2〜17のタイルを使用します。避難所の施設名・座標・対象災害・種別は未確認のため、避難誘導には使用しません。

画面に表示する画像・記述には、資料種別、出典URL、ライセンス、利用状況、位置精度、確認日を持たせています。確認できていない画像は「開発用プレースホルダー」、確認できていない記述は「未確認」と表示します。
